# WhatScares — Working in this repo

## Architecture
- No framework, no bundler. Static pages + one Vercel serverless API.
- `index.html` — homepage & core app: inline `<style>` + inline `<script>`, catalog data from `movies.js` (`const M`, 136 films, TMDB poster paths).
- `find-your-fear.html` — self-contained interactive game, reuses `movies.js` + atmosphere layer.
- `movies/*.html` (136 + hub) and `sitemap.xml` — GENERATED by `scripts/build-movie-pages.mjs`. Never edit generated files; edit the template and regenerate.
- `lists/*.html`, `articles/*.html` — hand-maintained static pages, no generator.
- `api/mood-search.js` — mood search API (needs `MINIMAX_API_KEY` in `.env`; local dev via dev-server).

## Commands
- `npm run dev` — dev server at http://localhost:3460
- `npm run build:movies` — regenerate film pages + sitemap after editing the template or catalog
- `npm run seo:ping` — IndexNow ping

## Parallel sessions
- More than one agent session is often running against this repo at once. Work in a git worktree, not the shared checkout — otherwise another session's `git commit -a` sweeps up your in-progress edits and lands them under an unrelated message.
- Before merging back, check the main checkout is clean. Never stash or discard changes you did not make; back them up and wait, or ask.
- `dev-server.mjs` serves the directory it lives in, not `process.cwd()`. A worktree preview needs its own `.claude/launch.json` entry pointing at that worktree's copy, or you will silently preview the main checkout.

## Design system
- Concept: "A Field Guide to Fear" — analog horror archive. Spec: `docs/field-guide-design-system.md`.
- `atmo.css` + `atmo.js` — shared atmosphere layers (grain / vignette / flicker / flashlight). Include in `<head>`, add the `.atmo` div after `<body>`. Palette lives in each page's `:root`.
- Fonts: EB Garamond (display/serif), Inter (UI), Courier Prime (`--mono`, archival labels).
- CSS convention: new design rules are APPENDED after original rules in the same `<style>` block; equal-specificity cascade does the overriding. Keep it that way.
- Always respect `prefers-reduced-motion` for anything that flickers, drifts, or types.

## Conventions & gotchas
- `slugify()` in page JS must stay identical to the one in `scripts/build-movie-pages.mjs` (clean apostrophes: `rosemarys-baby`).
- localStorage keys: `whatscares_user` (collection), `ws-lights` (flashlight pref), `ws-diagnosis` (Threshold result; index hero reads it).
- Supabase auth is client-side only (`supabase-js` CDN); sync logic lives in index.html.
- posters: TMDB `w92/w185/w342/w500/w780` depending on context.
